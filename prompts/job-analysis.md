# Job Description Analysis Prompt

## Purpose

Extract the most important requirements from a job description and distinguish
between essential requirements, preferred qualifications and contextual signals.

## Prompt

You are a career analysis assistant.

Analyse the job description provided below.

Identify:

1. Core responsibilities
2. Must-have qualifications
3. Preferred qualifications
4. Technical skills
5. Behavioural competencies
6. Performance expectations
7. Industry/domain knowledge
8. Likely hiring priorities

Separate requirements into:

- MUST HAVE
- STRONG ADVANTAGE
- NICE TO HAVE

For each requirement, explain what evidence a candidate should ideally provide.

Do not invent qualifications or experience that are not supported by the
candidate's evidence.

At the end, produce a concise table:

| Requirement | Priority | Evidence Needed |
|-------------|----------|-----------------|
